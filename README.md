# المساعد الصوتي العربي المحلي (OVOS Android Assistant)

تطبيق مساعد صوتي محلي ذكي لنظام أندرويد باللغة العربية، مبني ومقتبس من نواة **OpenVoiceOS (`ovos-core`)**، ومصمم ليعمل بكفاءة وسرعة فائقة دون الحاجة للاتصال بالإنترنت (**100% Offline-first**).

---

## 🌟 الميزات الرئيسية
- **معمارية OpenVoiceOS الكاملة:**
  - ناقل رسائل وأحداث غير متزامن (`AndroidMessageBus`) متوافق مع OVOS MessageBus.
  - موزع النوايا (`IntentDispatcher`) ومزخرف المهارات `@intent_handler`.
  - معالجات مهارات مستقلة (`OVOSSkill`) للتحيات، الوقت، الطقس، التحكم الصوتي، والمعارف.
- **محرك فهم لغوي طبيعي عربي فائق السرعة (Arabic NLU Engine):**
  - نموذج محلي خفيف الوزن يعتمد على TF-IDF مع n-grams (1, 2) ومصنف انحدار لوجستي متوازن.
  - استدلال لحظي بزمن يقل عن **1 مللي ثانية** على الجهاز.
  - حجم ملف أوزان النموذج **1.2 ميجابايت فقط** (`model_weights.json`).
- **تكامل مجموعة البيانات العربية:**
  - مدمج مع مجموعة بيانات `arabic-instruct-chatbot-dataset` (أكثر من 52,000 زوج محادثة) ومصنفة ضمن `intents.json`.
- **التشغيل المدمج في أندرويد (Chaquopy):**
  - يعمل محرك بايثون بالكامل داخل تطبيق أندرويد باستخدام مكتبة Chaquopy.
  - ربط كامل بلغة Kotlin وواجهة مستخدم عصرية بتصميم عربي (RTL).
  - دعم التعرف على الصوت باللغة العربية (`SpeechRecognizer`) والنطق الصوتي المحلي (`TextToSpeech`).

## 🚀 كيفية بناء حزمة APK

### 1. البناء التلقائي عبر GitHub Actions:
بمجرد رفع الكود إلى المستودع، يتم تفعيل سير عمل `.github/workflows/build-apk.yml` تلقائياً، ويمكنك تنزيل ملف `app-debug.apk` مباشرة من تبويب **Actions** أو صفحة **Releases**.

### 2. البناء محلياً عبر Android Studio أو سطر الأوامر:
```bash
./gradlew assembleDebug
```
ستجد الحزمة المنتجة في المسار:
`app/build/outputs/apk/debug/app-debug.apk`
